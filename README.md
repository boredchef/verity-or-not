## what do i do.
my features concise of 
* keep score and highest score!
* save progress and come back (but run out of time)
* each question has specific set time
* view your performance on each question
* restart whole save by pressing "r"
* smiley face background :DDD

## how it work
the html uses different containers for start, questions, score and review and are hidden/styled through css. the javascript manages the games views and sets them accordingly to what the variables want them to be. objects are used to create the questions, answer buttons, populate review container and make a save.
